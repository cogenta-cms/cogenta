Wait for readiness, then run:
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }}

Back up the database and /data before upgrading. Preserve your existing values:
  helm upgrade {{ .Release.Name }} oci://ghcr.io/cogenta-cms/charts/cogenta -n {{ .Release.Namespace }} -f private-values.yaml --set image.tag=<release>
Inspect history and roll back a compatible release:
  helm history {{ .Release.Name }} -n {{ .Release.Namespace }}
  helm rollback {{ .Release.Name }} <revision> -n {{ .Release.Namespace }} --wait
Rollback does not undo database migrations. Restore a verified backup if required.

PVCs and generated Secrets are kept on uninstall. Delete them manually only after verifying backups.
