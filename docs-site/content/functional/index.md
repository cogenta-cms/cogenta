# Documentation fonctionnelle

Pour qui administre un site Cogenta — pas pour qui le développe (voir la
[documentation technique](../technical/index.html) pour ça). Organisée comme
les guides WordPress, Drupal ou Strapi : par ce que vous voulez **accomplir**,
pas par le nom d'un écran de l'admin.

| Vous voulez… | Lisez |
|---|---|
| Installer un nouveau site, ou comprendre le premier écran de connexion | [Démarrer un site](demarrer-un-site.html) |
| Créer, classer, traduire, publier et faire relire du contenu | [Gérer le contenu](gerer-le-contenu.html) |
| Changer l'apparence, construire une page visuellement, gérer les médias | [Personnaliser l'apparence](personnaliser-lapparence.html) |
| Ouvrir une boutique, gérer produits, commandes et paiements | [Vendre en ligne](vendre-en-ligne.html) |
| Faire travailler un agent, discuter avec l'assistant, indexer vos documents | [Travailler avec l'IA et les agents](ia-et-agents.html) |
| Créer des comptes, distribuer des rôles, sécuriser les accès | [Comptes et accès](comptes-et-acces.html) |
| Régler le SEO, la sécurité, le menu, les intégrations | [Régler le site](regler-le-site.html) |
| Sauvegarder, restaurer, mettre à jour, surveiller le site | [Exploiter le site](exploiter-le-site.html) |

**Honnêteté de portée** (à lire une fois) : ces pages couvrent en profondeur
ce qui compte le plus aujourd'hui — le contenu, l'apparence, et l'IA/les
agents, section la plus récente et la plus mal expliquée jusqu'ici. Les
autres pages posent la structure et les tâches principales sans détailler
chaque champ de chaque écran ; elles se complètent au fil de l'eau. Chaque
page le dit explicitement quand une section reste volontairement sommaire.
