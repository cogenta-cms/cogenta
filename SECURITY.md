# Security Policy

## Reporting a vulnerability

**Do not open a public issue for security problems.**

Report privately through GitHub's private vulnerability reporting:
[Security tab → Report a vulnerability](https://github.com/cogenta-cms/cogenta/security/advisories/new).

You will get an acknowledgement within 72 hours and a first assessment within 7 days.

Please include: affected version, reproduction steps, expected and actual behaviour,
and the impact you believe it has. Proof-of-concept code is welcome.

## Scope

In scope: the Cogenta core, official plugins and themes, the CLI, and the installer.

Out of scope: third-party plugins and themes (report to their authors), issues
requiring physical access, social engineering, and vulnerabilities in dependencies
already publicly disclosed and tracked.

## Disclosure

We follow coordinated disclosure. Once a fix is available, an advisory is published
on GitHub Advisory Database with credit to the reporter, unless anonymity is requested.

Please give us reasonable time to ship a fix before public disclosure.

## Supported versions

The project is pre-alpha. Until 1.0, only the latest release receives security fixes.

## Bug bounty

None yet. This policy exists from day one regardless.
