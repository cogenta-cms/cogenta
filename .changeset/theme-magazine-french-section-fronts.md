Set a section or author front in the page's own language, and close its rows.

The line above a term's name on a section front ("SECTION", "AUTHOR") was the taxonomy's machine name, so a French site read English over every rubrique; it is now "Rubrique" or "Auteur" on a French page (and "Section", "Author" on an English one, sentence-cased for any taxonomy the theme has no word for). A French pull quote is set in « guillemets » with a no-break space inside, instead of English curly quotes.

The double rule under a section's name stopped forty pixels short of the column on each side when the page has a sidebar, and the lead's headline took five lines at the size a photograph would have filled. The rule now spans the column, the headline is one size smaller, and the number of briefs beside the lead is chosen so that the row beneath always closes full: no lone story left on its own under a wide white gap.
