**The site plan and the theme workshop stop being two unrelated screens.**

They were watertight: `/create-site` analysed an operator's documents into a
brief — what the activity is, who it is for, how it should sound — proposed a
content model, pages and a palette, and stopped. `/admin/theme-generator` then
asked that same operator to describe their site again, from scratch, in an
empty box. Two halves of one promise, with nothing between them.

A reviewed plan now offers "Générer le thème à partir de ce plan", and the
workshop opened that way starts with the analysed brief already written and
editable, saying where it came from. The uploaded documents deliberately do
not travel with it — a plan stores the brief it derived, not the files it
derived it from — so a reference screenshot is attached in the workshop's own
drop zone, which is where it belongs anyway.
